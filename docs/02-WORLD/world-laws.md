# World Laws

**Status:** Proposed specification. This document does not by itself imply implementation.
**System:** Strange Studio · Observable Intelligence Operating System (OIOS)

## Purpose

Describe the intended role of world laws within Strange Studio.

## Invariants

1. Truth over theater.
2. Every visible state has provenance or is labeled illustrative.
3. Cause and effect are traceable where known.
4. Unknown is a valid state.
5. Simulation is distinct from live operation.
6. Verification, approval, and delivery are separate gates.
7. Concepts are not implementations.

## Implementation boundary

This document is part of the design corpus, not evidence of a completed runtime component. Track implementation and verification separately.
