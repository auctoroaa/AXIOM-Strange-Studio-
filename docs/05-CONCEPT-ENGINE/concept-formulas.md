# Concept Formulas

**Status:** Proposed specification. This document does not by itself imply implementation.
**System:** Strange Studio · Observable Intelligence Operating System (OIOS)

## Purpose

Describe the intended role of concept formulas within Strange Studio.

## Master formula

Concept = Meaning + Function + Human Model + Truth + Causality + Space + Visualization + Interaction + States + Verification.

This is a review checklist, not arithmetic. See [CGE v1.0](../concept-generation-engine.md).

This document is part of the design corpus, not evidence of a completed runtime component. Track implementation and verification separately.
