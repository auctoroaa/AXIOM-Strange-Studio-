# cgc-engine

Owns concept seed generation, meaning analysis, function extraction, human-model analysis, observability design, architecture generation, quest generation and concept lifecycle.

Lifecycle: Seed -> Meaning -> Function -> HumanModel -> Observable -> Truth -> Causality -> Architecture -> Verification -> Delivery.

This engine generates candidate architectures and cannot certify its own output. The CGC pack manifest remains separate from the engine.

Status: package boundary documented; executable implementation pending.
