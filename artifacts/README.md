# Trust Artifacts

- evidence/: validation findings, test evidence and provenance references.
- certificates/: AXIOM-AAA certificate artifacts only.
- traces/: execution traces and observable event records.
- governance/: trust-policy decisions, revocation records and audit events.
- reports/: human-readable assurance and certification reports.

Do not commit secrets, private signing keys or fabricated evidence. Reports must identify real, simulated and unverified results.
